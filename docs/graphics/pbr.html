由浅入深理解 PBR

PBR，全称 Physically Based Rendering，中文常叫“基于物理的渲染”。它不是某一个神秘算法，而是一套让材质在不同光照下更稳定、更像真实世界的渲染思想。

从直觉开始 材质参数可视化 金属度 / 粗糙度 / 菲涅耳

1. 先用一句话理解 PBR

传统做法常常是“调到看起来差不多”：这里加一点高光，那里压一点颜色。PBR 的目标是：材质参数尽量对应真实物理属性，让同一块木头、金属、塑料，在室内、室外、强光、弱光下都比较合理。

最重要的直觉：PBR 不是让画面一定更漂亮，而是让材质更“守规矩”。光怎么来，能量怎么反射，哪些被吸收，哪些形成高光，都尽量遵守现实规律。

传统经验式材质

高光、亮度、颜色往往靠人工感觉调。换一个光照环境后，可能突然太假、太亮或太暗。

PBR 材质

用基础色、金属度、粗糙度等参数描述材质。换环境时，结果更可预测。

2. 真实感来自哪里？

你看到一个物体，本质上是在看“光和材质交互之后返回到眼睛的结果”。PBR 把这个过程拆成几件事：

光照太阳、灯、环境贴图给物体输入能量。
表面表面有颜色、粗糙程度、是否是金属。
反射一部分形成漫反射，一部分形成镜面高光。
相机视角不同，看到的亮度和边缘反光也不同。

这就是为什么同一个杯子，正面看和斜着看不一样；为什么磨砂塑料没有锐利高光；为什么金属的反射会带有自己的颜色。

3. PBR 常见的四个核心参数

Base Color

基础色

材质本身的颜色。非金属时，它更像“漫反射颜色”；金属时，它会明显影响反射高光的颜色。

Metallic

金属度

0 表示木头、塑料、皮肤等非金属；1 表示铜、铁、金等金属。现实中多数材质不是 0 就是 1，中间值常用于过渡或脏污混合。

Roughness

粗糙度

粗糙度越低，高光越小越锐利，像镜子；粗糙度越高，高光越大越散，像磨砂表面。

Normal

法线

法线贴图不真的改变模型轮廓，但会改变表面每个点“朝向哪里”，让凹凸纹理影响光照。

4. 漫反射和镜面反射

一个非金属物体，比如木头，光打上去后会有两种主要结果：

类型可以怎么想画面表现
漫反射 Diffuse光进入表面浅层，被散射后带着材质颜色出来。决定大面积颜色，比如木头是棕色、塑料是蓝色。
镜面反射 Specular光在表面直接弹回来。决定高光、反光、边缘亮度。

金属比较特殊：金属几乎没有普通意义上的漫反射，大部分能量都进入镜面反射，而且反射会带上金属自身的颜色。所以金、铜、铝看起来差异很大。

5. PBR 背后的三个物理约束

能量守恒

反射出去的光不能凭空超过照进来的光。材质越强烈反射，高光越亮，漫反射通常就越弱。

微表面模型

看似平滑的表面，其实由许多微小镜面组成。粗糙度越高，这些小镜子的朝向越乱，高光越散。

菲涅耳效应

越是贴着表面斜看，反射越明显。水面、玻璃、塑料边缘变亮，很多时候就是它在起作用。

线性空间

计算光照时通常要在线性空间处理，最后再转回屏幕显示。否则混色和亮度会不符合真实光的叠加方式。

6. 一个简化版 PBR 公式

真实引擎里的公式会更复杂，但可以先记住这个结构：

最终颜色 ≈ 漫反射 + 镜面反射 + 环境光反射

其中镜面反射又会被粗糙度、视角、法线、金属度共同影响。你在游戏里看到的“真实材质”，通常不是一张颜色图决定的，而是多张贴图一起工作。

7. 在游戏和 WebGL 里怎么用？

现代引擎通常提供两套常见工作流：

工作流常见贴图适合理解方式
Metallic / RoughnessBaseColor、Metallic、Roughness、Normal、AO最常见。用“是不是金属”和“表面粗不粗”来描述材质。
Specular / GlossinessDiffuse、Specular、Glossiness、Normal更直接控制高光颜色和光滑度，但参数管理更容易混乱。

Unity、Unreal、Blender、Three.js、Babylon.js 都支持 PBR 思路。不同软件名字可能略有不同，但核心问题都一样：材质如何反射光。

8. 新手最容易混淆的点

粗糙度不是亮度。 粗糙度改变的是高光集中还是分散，不是简单地把物体调亮或调暗。

金属度不是“看起来高级”。 木头、皮肤、石头、塑料通常都应该接近 0。把所有东西调成半金属，会让画面发灰发脏。

基础色不要自带强烈光影。 PBR 贴图里的 Base Color 最好描述材质颜色本身，阴影和高光交给光照系统算。

环境光很重要。 没有环境反射，再好的金属也会像黑球，因为它没有东西可反射。

9. 最后建立一个心智模型

理解 PBR，可以把自己想成一个材质侦探。看到一个物体时，不要先问“它该多亮”，而是问：

它是什么颜色？

这对应 Base Color。

它是不是金属？

这对应 Metallic。

它表面光滑吗？

这对应 Roughness。

它表面有细节吗？

这对应 Normal、AO 等贴图。

当这几个答案比较真实，再给它合理的光照和环境反射，PBR 的真实感就自然出来了。
