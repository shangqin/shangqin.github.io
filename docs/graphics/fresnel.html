由浅入深理解菲涅尔效应

菲涅尔效应说的是：同一个表面，正着看和斜着看，反射强度不一样。越贴着表面看，反射通常越强。这就是水面、玻璃、塑料、金属边缘会突然亮起来的原因之一。

从水面直觉开始 观察角交互演示 连接 PBR 边缘反光
正面较多看到水下 / 材质本色
反射较弱看到天空倒影
普通视角当前视觉感受

1. 先从一个生活现象开始

你站在水边往下看，常常能看到水里的石头、鱼、河底。但当你把视线压低，几乎贴着水面向远处看时，水面会更像一面镜子，天空和岸边的倒影变得特别明显。

这不是水面突然变成镜子，而是“观察角”改变后，水面对光的反射比例变大了。这个随角度变化的反射现象，就是菲涅尔效应。

2. 什么是菲涅尔效应？

用最简单的话说：

越垂直看表面，越容易看到表面下面或材质本色；越斜着看表面，越容易看到反射。

这里的“斜着看”在图形学里常叫掠射角。比如你看一个球，球中心比较像正面视角，球的边缘就接近掠射角。所以很多材质的边缘会更亮、更反光。

3. 为什么边缘会发亮？

把球表面想成很多小平面。球中心的小平面大多正对你，球边缘的小平面则是斜着对你。根据菲涅尔效应，斜着看的地方反射更强，于是边缘就会出现一圈更明显的反光。

正面区域：反射较弱

过渡区域：反射增强

边缘区域：反射最明显

4. 它和材质有什么关系？

菲涅尔效应几乎存在于所有材质里，只是强弱不同。水、玻璃、塑料、皮肤、木头、金属都会有，只是表现方式不一样。

材质正面看斜着看 / 边缘看
水更容易看到水下内容更像镜子，天空倒影增强
玻璃透明感更明显反光更强，边缘更亮
塑料 / 木头主要看到材质颜色边缘会有一层淡淡反光
金属本来就很会反射反射仍会随角度变化，但整体都更亮、更有环境倒影

5. PBR 里怎么计算它？

真实的菲涅尔公式来自物理光学，会考虑折射率、偏振等因素。实时渲染里常用一个近似公式，叫 Schlick 近似：

F = F0 + (1 - F0) × (1 - cosθ)5

不用被公式吓到，先看三个部分：

F

最终反射比例。它越大，表面越反光。

F0

正面看时的基础反射率。非金属通常比较低，金属通常更高且带颜色。

cosθ

视线和表面法线的夹角关系。越正对，cosθ 越大；越斜看，cosθ 越小。

五次方

让变化不是线性的：大部分角度变化不夸张，但接近边缘时反射会快速增强。

6. 和 PBR 参数如何配合？

菲涅尔不是单独工作的。它会和粗糙度、金属度、环境反射一起决定最终观感。

参数对菲涅尔观感的影响
粗糙度 Roughness粗糙度低时，边缘反射更锐利；粗糙度高时，反射会被打散，看起来更柔。
金属度 Metallic金属的 F0 更高，反射往往带有金属颜色；非金属正面反射通常较弱。
环境贴图 Environment菲涅尔增强的是“反射”，所以环境里有什么，边缘就可能反射什么。
法线 Normal法线改变局部表面朝向，也会改变每个像素的菲涅尔强弱。

7. 开发中怎么判断用对了？

看水和玻璃

正面透明、斜看反光，是最典型的检查方式。

看球体边缘

边缘应该有自然的反射增强，但不能像描边一样死白。

换环境光

材质边缘应该能反映环境变化，而不是固定一圈亮色。

别手动画假边光

如果只是加一圈固定 rim light，可能在某个角度好看，但换视角就不真实。

8. 一句话总结

菲涅尔效应就是“反射会随观察角变化”：正面看反射弱一些，斜着看反射强很多。它解释了水面为什么低角度像镜子，也解释了 PBR 材质为什么边缘常常更亮、更有真实感。
